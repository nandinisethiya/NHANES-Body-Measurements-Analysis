# Body Measurements Analysis — NHANES Dataset

**By Nandini Sethiya**

**Dataset:** NHANES Body Measurements  
**Tools:** Python, Google Colab, pandas, NumPy, Matplotlib, Seaborn

## About the Project

This project analyzes body measurement data from the NHANES dataset. It explores height, weight, BMI, waist circumference, hip circumference, and related measurements using data cleaning, exploratory data analysis, and visualizations.

## View the Notebook

Open `Body_Measurements_Analysis.ipynb` to view the complete analysis, visualizations, and results.

## How to Run

1. Download `Body_Measurements_Analysis.ipynb`.
2. Open it in Google Colab.
3. Connect your Google Drive if the dataset is stored there.
4. Run the cells from top to bottom.
